Adapted files:
- CodexDesktopIPCClient.swift: desktop follower transport, framing, peer/owner/revision validation and reconnect; all approval/answer submission entry points removed and outgoing observation/refusal messages allowlisted.
- CodexDesktopRequestProjection.swift, CodexActivityTaskIdentity.swift and CodexActivitySubagentIdentity.swift: current-turn/wait projection and source classification.
- CodexLocalRolloutActivityClient.swift: bounded incremental cursor, file replacement handling and complete-line buffering adapted to the existing local decoder.
- IslandConceptBoard.swift: fixed-canvas surface, path/content transitions, pointer routing and task-card hierarchy.
- IslandTaskScrolling.swift: row anchors, viewport intersection and boundary-only visibility publication.
- CodexActivityStateSmoke.swift: complete State Smoke, Quantum Noise and Liquid Wave Metal renderer, profiles, simulation and preview host.
- IslandConceptBoard.swift and CodexActivityIsland.swift: native glass, notch geometry, full-card layout and material gradient.
- IslandScrollingText.swift: native scrolling text implementation.
- IslandConceptBoard.swift: compact fitting-title layout, activity/count placement and completion receipt cadence (task branch).
- CodexActivityCopy.swift: session token count formatter; QuotaViewCore local rollout/public-content decoders: cumulative usage field guards and public assistant content selection rules.
- AppPreferences.swift and SettingsView.swift: glass degree, screen-constrained width, native card/row/divider/icon/value-menu controls, effect-option button style and wallpaper-backed settings preview composition.
- CodexActivityIsland.swift: completion/confirmation edge glow, outline, palette, geometry and shared compositor pulse.
- SettingsIslandPreview assets: wallpaper and three effect thumbnails; Codex provider SVG.

Codex Monitor adaptations use local session/turn identity, event-driven read-only activity updates, a 680-point default expanded surface, selected-card effects and native NSScrollView gestures. QuotaView approval actions, archive and quota-capsule features are not included. Decorative visual progress is not a measured task-completion percentage.
